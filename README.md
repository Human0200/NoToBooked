# NoToBooked - фильтр забронированных товаров на Авито

Расширение для браузера, которое автоматически фильтрует (скрывает или размывает) забронированные товары в поиске и на главной странице Авито.

## Возможности
- **Скрывать полностью**: Полностью убирает забронированные карточки из сетки, сдвигая остальные товары на их место.
- **Размытие**: Применяет блюр к забронированным товарам. По клику блюр исчезает, позволяя просмотреть объявление.
- **Не фильтровать**: Показывает все товары без изменений.

## Ручная установка

Так как расширение работает на Manifest V3, процесс установки отличается для разных браузеров. 

### Установка в Chromium браузерах (Google Chrome, Edge, Яндекс.Браузер и т.д.)
1. Скачайте исходный код репозитория в виде ZIP-архива и распакуйте его на вашем ПК
2. В браузере перейдите на страницу расширений: `chrome://extensions/`
3. В правом верхнем углу включите **"Режим разработчика"**
4. Нажмите кнопку **"Загрузить распакованное расширение"** и выберите распакованную папку
5. Готово!
